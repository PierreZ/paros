Paxos in Rust · multi-tenant journals

paros

paros implements the Paxos family of consensus algorithms in Rust. parosd is a journal service built on it: a cell of machines keeps ordered logs for many tenants.

Learning projectNot for productionSource

A session

shellthree parosd machines on this host
# Form a cell from the listed machines.
$ parosctl init --members "$PAROSCTL_SERVERS"
# A tenant owns journals. A journal is an ordered log of records.
$ parosctl tenant create acme
$ parosctl journal create acme orders
# Paxos chooses each record on a majority of acceptors.
$ parosctl write "$J" hello world --leader 7
$ parosctl read "$J"

Run it yourself: DEMO.md in the repository starts the three machines.

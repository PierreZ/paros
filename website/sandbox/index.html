paros sandbox

Watch a paros cell run in your browser. Every machine runs the same code as parosd, and the operator uses the same calls as parosctl. How the sandbox works · paros
The network, the disks and the clock are simulated. Times are simulated milliseconds, not production numbers. A run depends only on its seed, its configuration and its action log, so the link to this page replays it exactly.

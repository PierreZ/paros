paros playground

A tool to understand Paxos and paros: run a paros universe in your browser, drive it, break it and watch it recover. Every machine runs the same code as parosd, and the operator uses the same calls as parosctl. How the playground works

The network, the disks and the clock are simulated. Times are simulated milliseconds, not production numbers. A run depends only on its seed, its configuration and its action log, so the link to this page replays it exactly.
